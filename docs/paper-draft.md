# Diffusion-Guided Speculative Decoding: A Hybrid Approach for Accelerating Tool-Calling in Automotive Assistants

## 摘要

车载语音助手需要在严格延迟和有限算力约束下，将用户指令快速转换为可靠的工具调用。传统自回归大语言模型能够提供较高的结构化调用准确率，但逐 token 解码带来较高首包延迟，难以满足实时车载交互需求。本文提出 Diffusion-Guided Speculative Decoding，一种面向车载工具调用的混合解码方法。该方法使用 100M 量级扩散模型并行生成完整 JSON 草稿，再由 1.5B 量级自回归模型进行验证和纠错。对于结构合法且置信度较高的草稿，系统直接接受；对于低置信度或结构非法的草稿，系统触发自回归验证器进行局部修正。预期该方法可在保持 90% 以上工具调用准确率的同时，将平均响应延迟降低 2 到 4 倍。

**关键词：** 车载语音助手；工具调用；扩散模型；投机解码；低延迟推理

## 1. 引言

车载语音助手正在从简单命令识别演进为具备复杂工具调用能力的智能代理。用户可能要求系统完成空调调节、导航设置、媒体控制、车窗控制等操作，这要求模型输出严格合法的结构化 JSON。该场景对延迟极其敏感：过长响应会破坏交互体验，并可能影响驾驶安全。

现有方案通常使用 3B 级别自回归模型生成工具调用。此类模型准确率较高，但逐 token 生成机制限制了响应速度，首包延迟常超过 1 秒。另一方面，小模型虽然速度更快，但容易产生字段缺失、JSON 非法或参数错误。本文关注的问题是：如何在车载平台资源受限的条件下，同时获得低延迟和高工具调用可靠性。

## 2. 方法概述

本文提出扩散引导的投机解码框架。系统由三个核心模块组成：

1. **扩散草稿模型。** 采用 ELF 105M 或 DiffuGPT-127M 等小型扩散模型，在单次或少量去噪步中并行生成完整工具调用草稿。
2. **结构校验与置信度路由。** 对草稿执行 JSON 合法性、字段约束、工具 schema 和置信度检查。
3. **自回归验证器。** 使用 Phi-1.5 或 TinyLlama-1.1B INT4 模型验证草稿，仅修正错误 token 或非法字段。

该流程借鉴 speculative decoding 的接受机制，但将传统小自回归草稿模型替换为并行扩散模型，从而降低草稿生成延迟。

## 3. 训练与推理设计

训练阶段采用两阶段对齐蒸馏。第一阶段使用标准监督损失训练扩散模型生成工具调用序列；第二阶段参考 DEER 框架，通过蒸馏损失使扩散模型输出分布贴近自回归验证器。推理阶段采用单步解码与自适应草稿长度策略：当置信度较高时直接接受完整草稿，当置信度不足时缩短草稿或触发验证器。

为降低结构错误，系统将在解码阶段加入约束采样，限制每个位置的合法 token 类型，例如括号、字段名、枚举工具名和数值范围。

## 4. 实验计划

数据集计划包含 2000 条以上车载工具调用指令，覆盖空调、导航、媒体、车窗、座椅等场景。实验将比较四类系统：纯 3B 自回归模型、纯扩散模型、标准投机解码，以及本文提出的扩散-自回归混合方案。

评估指标包括首包延迟、总响应延迟、P50/P99、JSON 合法率、精确匹配率、工具调用准确率、吞吐量和显存占用。消融实验将分析置信度阈值、草稿长度、去噪步数和量化策略对性能的影响。

## 5. 预期贡献

本文预期贡献包括：

1. 将扩散模型作为投机解码草稿生成器引入车载工具调用任务。
2. 提出扩散模型与自回归验证器的联合对齐训练方法，提高草稿接受率。
3. 设计面向车载低延迟场景的自适应单步解码策略。
4. 建立覆盖车载控制任务的工具调用评估流程。

## 6. 挑战与应对

扩散模型可能生成结构非法 JSON，因此需要 schema 约束和合法 token 采样。双模型切换可能引入额外开销，因此验证器需要预热并复用缓存。实际部署到 Orin 等边缘平台时，还需要结合 INT4 量化、TensorRT 加速和内存占用优化。

## 7. 结论

Diffusion-Guided Speculative Decoding 试图结合扩散模型的并行生成能力与自回归模型的可靠纠错能力，为车载工具调用提供低延迟、高可靠的混合推理路径。后续工作将围绕数据集构建、原型实现、基线对比和消融评估展开。
